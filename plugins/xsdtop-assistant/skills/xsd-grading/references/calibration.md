# 评分一致性与复核案例

先读当前资料包的原卷、评分依据和教师说明。相同题号可能对应不同卷版或题序，提交编号和快照决定归属；不从旧任务搬分值、评语或教师口径。

## 批量与接续

对同题选可确认的不同作答情况核对评分口径：有效方法、关键步骤、结论、证据状态与依据。使用现有逐题结果保存，不新增协议字段或另造一份可覆盖人工终判的总分。发现前后口径不同先回看原图与规则，再修正有证据的结果；不能按同学多数写法确定标准答案，也不能用平均分把不同作答硬拉齐。

同题比较只用于一致性检查，不在学生报告中披露其他人的姓名、作答或成绩。只下载/试批的范围不因发现问题扩展为批量回写。

## 典型情况

| 情况 | 处理 |
| --- | --- |
| 方法与参考解析不同，但成立 | 按题意和当前评分依据判断有效步骤，不因解法不同判错 |
| 前一步算错，后续沿用该值但方法有效 | 回到实际 rubric 判断可得分步骤，不机械全部扣完；没有细则时不冒充教师已规定连带扣分 |
| 答卷有字但 OCR 为空 | 回原图判断，不当 `BLANK`；仍看不清按待复核状态留空分数和判定 |
| 答题卡题号与原卷不一致 | 用原始资料与快照核对映射，无法唯一匹配用 `UNMATCHED`，不靠相邻顺序补齐 |
| 参考答案与题意冲突 | 记录 `referenceDoubt` 给教师，公开报告不包含内部裁决请求，不擅改网站标准答案 |
| 同样正确结论，一份有过程一份无过程 | 按该题真实过程要求判断，不假定所有解答题或客观题同一规则 |

## 写出可执行的建议

将“知识或方法”“实现/运算”“读题与条件”“时间取舍”作为排查方向，根据具体作答确定；单次错题不足以推断长期习惯或心理。建议指向题号及可做的动作，例如重算一个中间量、补单位、用边界例子检验结论；必要时给合适的补练量，不承诺固定提分。

结构化字段、报告正文和回写结果使用同一事实。公式显示与评分一致性分开检查：本地预览不能证明手机端或 PDF 已通过，未检查的出口如实标明，不为看预览重复触发网站 AI 阅卷。

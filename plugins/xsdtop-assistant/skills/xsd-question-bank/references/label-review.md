# 题目匹配与已有标签复核

本参考用于存量题与本地资料交叉核验；新题录入的标签和五维评分仍遵循 [question-metadata.md](question-metadata.md)。题目ID、标签ID和当前状态必须在本次学科权限内核实。

## 先证明是同一道题

优先比对可核实的来源题号、题面条件、数据范围、选项、图、样例和答案；标题、人名或同一章次只能提供候选。站内可能改过人名和题名，题面内容也可能以图片为主。

字符n-gram、包含度或相似度用于缩小候选，不能靠历史某批阈值自动定案。同名不同题、相同模型但不同条件、缺图题、残缺OCR题都需要人工比对。无法唯一匹配时保留候选与差异，不向任意一题补标签。

整场合写的题解先按题号和题面边界切分，再提取本题证据；Markdown围栏里的样例输入输出不是标程，不能把数字样例当源码分析。

## 标签证据

- 优先题目本身要求、作者对本题的明确考点说明，以及完整正确解法实际用到的知识点。
- 部分分、错误方法、被否定的方案或“可以想到但会超时”的算法不能直接变成本题标签；检查上下文而非只看关键词。
- 资源库自带的分类、关键词子串匹配和旧AI标签都只是待审候选。通用词“模拟”“枚举”等出现于标题或“模拟赛”中不构成考点证据。
- 读取 `list_question_labels` 当前启用的本学科目录，按完整路径区分同名节点；不用记忆中的ID、另一学科标签或开发库映射。
- 新增和删除分别列依据。存在其他正确解法时，不能因为当前题解没用某标签就认定该标签错误。零标签不是必须塞满，证据不足则留空。

复核表记录：已核实题目、来源匹配依据、原标签、建议保留/新增/删除、对应题面或解法证据及待确认项。未经授权不建新标签树，不把批量标签覆盖到每道题。

## 在授权内修改

先提供确定项与存疑项。只读审查不写；已明确授权的修正无需重复请求同一许可。追加已核实标签时也必须先读取完整 `labelIds`，保留所有未修改标签，再发完整数组；不要把“建议新增集合”直接当替换数组。

删除标签关联或其他破坏性修改须有对应明确授权；删除题目、题单、目录仍按主 skill 的明确确认流程。修改前复读当前题目及最新标签树，发现并发变化或标签已停用就重新评估。

写后核验完整标签集合、学科及可用状态，确认未改题干、答案、评分和公开状态。将“建议修正”“已修改”“待复核”分别统计；不把算法相似性或分类器分数当成事实正确率。

# 讲义动画演示

每次收到制作、继续、修改、验收、上线讲义动画或排查演示加载的请求，先调用 `prepare_handout_lab`，然后读取本次成功返回的 `entrypoint`，按原版 handout-lab 执行。配套文件相对返回的 `resourcesDir` 解析；原文中 `.claude/skills/handout-lab/` 指向这个资源目录，其余项目路径从当前 xsdtop 工程解析。

即使此前读取过规则或已有本地资源，每次请求仍需先调用该工具检查当前权限。工具失败、缺失、超时或后台拒绝时停止本次操作，如实报告原因；不得通过历史路径、会话里已加载的内容、工程中的另一份 handout-lab 或本地缓存继续。

技能包按需从后台指定的私有 COS 下载，原始内容不改写，不复制到插件安装目录或其他自动发现的技能目录。原版技能要求的工程依赖、上线顺序和操作授权仍然适用。

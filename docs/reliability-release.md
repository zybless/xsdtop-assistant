# 0.9.0 可靠性改进与发行核对

发行版本：0.9.0。配套网站开放通道协议：2。2026-10-19 发布前已核实生产接口返回协议2；用户需从插件市场更新并新建会话。

## 行为变化

- SQL 查询密钥必须绑定可用账号，且账号具有现有 `ai:query` 管理权限。它按数据库账号授权查询，不按密钥学科隔离。旧的未绑定 SQL 密钥需在后台补绑定；正常教师定位题单不需要 SQL 权限。
- `list_question_lists` 分页返回允许追加的题单名称和编号。私库限本人、当前学科及当前租户；官方限当前域及创建者权限。空跑和正式录题均核对目标题单，拒绝跨学科、跨域和类型混用。
- 正式录题必须传稳定 UUID `requestId`，插件直接使用已确认的校验编号。密钥行锁串行化同一密钥的提交；业务和 `import:receipt` 内部回执写入现有流水表的同一事务。响应丢失后同编号返回旧结果；相同编号的内容、身份、学科或落库类型改变时拒绝。流水中的内部回执不计入业务题量，统计调用量时应排除该动作。
- 插件空跑资料以600权限保存到配置目录的 `imports/`，30分钟有效，可在本机进程重启后继续；保存绑定身份与权限指纹。过期或缺失记录时先核对原结果，再决定新录入。不要清理仍需重试的回执。
- `get_question_edit_snapshot`、`get_question_list_edit_snapshot` 返回完整可编辑内容与版本。保存必须传 `expectedVersion`。聚合写入在串行化事务中锁主行并核对内容指纹，旧快照被拒绝；冲突后重读、合并本次修改，不能直接覆盖版本号重发旧数组。
- MinerU 超时覆盖响应体，上传/状态查询/下载均受单次调用预算限制。任务编号及未完成上传记录保存在本机，恢复时复用同一任务并核对原文件指纹。结果包限128MB、展开限512MB、单文件限64MB、最多4096条目；全新暂存目录解压通过后才落盘，不覆盖已有编辑结果。
- 讲义包改为从 Studio 的真实实现目录打包，保持文件原样；校验缓存内的完整文件指纹，缺失或改变后重新下载。每次使用先重新授权。
- `inspect_grading_package` 汇总本地下载、结果、校验、回写回执和待复核状态，供新会话恢复。它不代表网站当前状态；提交时仍检查权限、快照、文件和人工复核。
- 一并纳入内容校对、标签复核、TeX预处理和阅卷报告质量/本地预览增强。TeX及Studio制作仍需对应工程和运行依赖。

## 发布顺序

1. 完成后端、插件、前端定向测试，检查技能引用和发行包在仓库外的自包含性。
2. 将讲义技能打包为新的1.0.1或更高版本，不覆盖旧 COS 对象。私有包只上传私有桶，不进入公开插件包。
3. 部署配套后端与密钥管理前端，迁移需要保留的旧SQL密钥绑定。开放通道 profile 应返回 `protocolVersion: 2`。
4. 配置新讲义包版本、对象键及 SHA-256，再按已授权发行流程更新市场插件到0.9.0。
5. 更新安装并新建会话，检查 `get_access_profile` 返回的 `pluginVersion`、`protocolCompatible`、查询范围和实际权限。

新版插件会拒绝在旧后端执行受保护的正式录题及聚合编辑；新版后端会拒绝缺少请求号或快照版本的旧写请求，避免静默失去保护。配套发布期间应先完成后端部署，随后及时更新插件。

## 验证边界

自动测试覆盖录题回执复用与身份冲突、目标题单拒绝、编辑快照冲突、缓存损坏、解包资源、响应体超时、解压原子性、重启恢复和阅卷本地状态。HTTP端到端测试使用合成数据及本机模拟服务。单元测试不替代真实MySQL事务集成或生产部署验收。

2026-10-18 已补真实 MySQL 8.4.9 / InnoDB 集成验证：新增 `AiQuestionReliabilityMySqlTest` 的22项用例，连续三轮均无失败、无跳过；与现有助手及班级/集训营阅卷单测合跑183项通过。集成用例调用真实 Spring 事务、鉴权、业务 Service 和 MyBatis，覆盖官方/私库重复与并发提交、等待锁前已有旧读视图、回执失败/外层事务回滚、子项变更后的编辑冲突及学科/租户/所有者边界。外部 AI、Redis、COS 和订阅额度不属于这组事务验收范围，未调用真实服务。

该验证复现并修复了一个旧读视图问题：外层 RR 事务等到密钥锁后，普通回执查询仍可能看不到刚提交的回执，导致同请求号重复新建题单。修复保留密钥锁，事务内未命中时暂停旧事务读取已提交回执，同时保留同事务未提交回执的可见性；不对日志表施加会阻塞事务外审计插入的范围锁。

复跑入口：在 `SpringBoot/CodeArena` 下设置 `XSDTOP_AIQUERY_TEST_JDBC_URL`，执行 `python3 scripts/run-aiquery-mysql-tests.py --repeat 3`。仅接受本机非3306端口、`aiquery_test_*` 空库，临时实例数据目录须包含 `xsdtop-aiquery-mysql-`。需预先还原已有表结构；测试及复跑脚本不执行DDL，不加载业务数据源。缺少显式数据库配置、用例跳过或结果失败都会使复跑入口失败。日志、JUnit XML、重复运行摘要保存到指定报告目录；本次证据位于仓库 `output/xsdtop-assistant-mysql-20261018/`。此项通过不表示生产部署或安装版端到端验收完成。

教学质量验收需另外选取获授权的脱敏原卷、答卷和教师逐题评分，保存为固定样本。比较逐题分差、判定一致率、异常材料的待复核召回、误当零分数量，并人工核对报告是否与作答证据一致。先固定评分口径和目标学段，再比较不同模型；没有真实样本时不宣称评分准确率。现有日志、清单和JSON文件足以承载这项验收，不需要新增业务表。

# 班级与集训营本地阅卷

范围为班级的一次作业或测评、集训营的一次测评。网站提供资料、权限与版本校验、结果持久化；当前本地 Agent 实际查看答卷并完成推理、诊断和报告。复用现有测评提交、AI 阅卷记录与逐题评分表，无数据库结构变更。班级作业与测评复用同一外部结果校验、持久化与本地目录，分别关联现有提交表。

## 权限与接口

教学密钥必须绑定可用教师；后台管理和教师自助入口均可显式选择班级 `class-grading:read` / `class-grading:import` 或集训营 `camp-grading:read` / `camp-grading:import`。后台编辑只修改绑定与 scopes，不重签密钥。默认自助能力仍是私库录题和传图。每次请求先核验密钥有效性、绑定教师、学科，再检查请求租户内资源权限：营队需要助教以上，班级下载需学习委员以上有效读权限，回写需负责人有效写权限；从密钥取得教师身份，业务服务不读取网页登录上下文。

接口根路径为 `/api/ai-open/grading/{subjectId}/camps/{campId}/assessments`。

| 方法与相对路径 | 用途 |
| --- | --- |
| GET 根路径 | 查询该营测评列表 |
| GET `/{assessmentId}/package` | 清单、评分依据与提交快照；可选 submissionIds，最多100份 |
| GET `/{assessmentId}/files/{paper或analysis}?version=...` | 原卷与答案解析二进制，下载前后校验依据版本 |
| GET `/{assessmentId}/submissions/{submissionId}/answer-file?version=...` | 原始答卷，读取前后核对提交及依据版本 |
| POST `/{assessmentId}/submissions/{submissionId}/results` | dryRun 校验或单份事务导入 |

班级根路径为 `/api/ai-open/grading/{subjectId}/classes/{classId}`，GET 根路径返回含任务类型的作业和测评列表。任务相对路径为 `/{taskType}/{taskId}`，`taskType` 仅允许 `homeworks` 或 `assessments`；后续 `package`、`files/{kind}`、`submissions/{submissionId}/answer-file` 和 `results` 与营队契约一致。清单包含 classId、taskType、taskId，插件禁止同目录混用班级/营队或作业/测评。

下载走本站受控接口，不输出对象存储密钥或预签名地址；插件拒绝重定向，不将访问密钥发送到题面中的网址。当前列表沿用营队原有测评 VO；资料包中的文件统一为受控下载路径。

## 本地资料与结果

独立目录中保存 manifest.json、reference.md、rubric.json、paper.pdf、analysis.pdf、answer-提交编号.扩展名、results/提交编号.json、validation.json。清单包含固定批次、提交版本和文件 SHA-256。断点继续保留同一批次与快照；每次校验、回写均核对公共原件与当前处理的答卷。公共依据缺失会阻止整批，单份答卷缺失或损坏只使该份失败，其余完整答卷可以继续。单份 JSON 最多8MB，原始资料最多500MB，单文件64MB。网页不存在上传解析时调用现有教师版 PDF 排版，保存题库答案、解析及配图，不调用 AI。

结果不接受调用方指定满分、总分、记录来源、教师身份或文件引用。服务端以当前题单生成逐题骨架，严格校验恰好覆盖全部题号、分值范围、最多两位小数、判定一致性与真实空白。沿用现有成绩字段容量，计分题单每题满分1至9999、总满分不超过999999，超限时在下载前拒绝。识别异常必须空分空判定，needsReview 由服务器设置，任何待复核题都会使总分保持空值。

网站保留 report_md、结构化 AI 原判、证据页码和逐题诊断；provider 固定 external-agent，model 为客户端报告的模型，不能证明真实推理身份。原教练说明保持原字段长度，导入批次和快照版本另存已有 result_json 的 externalContext。逐题权威成绩仍用原评分明细，教师修改后 AI 原判保留。

## 并发、回滚与重试

资料版本涵盖题单题目编号与顺序、题面答案、满分、计分模式、教练说明及人工原卷、解析文件；提交版本还涵盖原答卷、绑定记录、重批次数及教师复核状态。修改评分依据、重交答卷、换绑记录或人工复核后，旧结果不能直接导入。

正式导入先锁测评、提交与已有阅卷记录，核验版本，再写阅卷记录、评分明细并换绑提交，处于同一事务。外部持久化方法要求调用方已有事务，不调度站内 worker、不发用量事件。单份失败整份回滚，其余提交可继续。网页复核及批量重阅的换绑同样持有提交锁，避免与导入交错覆盖。

请求键包含提交、教师、批次、快照和结果内容。相同请求重放返回原记录，迟到重放也不重新换绑提交。插件正式回写只使用同一密钥在24小时内校验通过且内容未变的结果，逐份落盘回执；更换结果需重新校验。网络响应丢失保留目录与原 JSON 重试，不新建批次。该本地校验记录是工作流保护，服务端每次实际导入独立核验版本与内容。

## 上线与真实联调

先部署配套后端和前端，确认反向代理放行已有 `/api/ai-open/**` 通道、保留 Authorization 且支持二进制附件。然后同步发行插件0.7.0，用户更新并新建会话，在已有密钥上显式勾选教学能力或签发新密钥。不需要迁移表结构。

自动化测试覆盖权限隔离、评分边界、未识别留空、陈旧快照、历史重放、记录保存、下载续传、文件篡改、校验后改稿、换密钥、响应丢失及真实 HTTP 下载边界。仓库测试没有连接生产数据库或处理真实学生答卷，仍须在测试环境以小批真实样卷完成以下验收：

1. 题单自动原卷、人工原卷、有上传解析、无上传解析各验证一组；确认题单题号与原卷实际题号一致，答案配图完整可读。
2. 覆盖计分和纯评测、扫描 PDF 与照片、同名学生、看不清及缺页；逐题核对网页展示、历史记录及教师复核后 AI 原判留存。
3. 在下载后修改题单、重交答卷、网页启动重批或教师改分，确认旧结果拒绝回写；模拟请求已成功但客户端未收到响应，确认重试只返回原记录。
4. 测量实际 Typst 生成时间、100份答卷下载耗时和 Agent 阅卷用量，再确定常用批次规模。准确率提升须用同一批样卷与教师金标准对比，不能仅根据改成本地 Agent 宣称提升。

## 隔离链路测试

`CampExternalGradingMySqlTest` 通过临时 MySQL 8.4、真实 MyBatis、事务、HTTP Controller 和发布版 stdio MCP 完成端到端检查。测试仅允许显式指定 `127.0.0.1` 上名为 `grading_test` 的隔离库；依赖从现有备份导入的营队与班级、作业、测评、提交、阅卷记录和评分明细10张原表结构，不提供或执行生产表结构变更。测试会清空隔离库中的这10张表，禁止指向共享业务库。

测试用纸保存在 `SpringBoot/CodeArena/src/test/resources/camp/external-grading`，全部为合成数据：两道物理题，一份7分答卷、一份含不可辨认答案的答卷。PDF 已逐页渲染核对。测试驱动使用固定金标准结果，验证资料下载、7分落库、异常题及总分留空、报告和作答证据保留、纯评测、原教练说明2048字符、回滚、并发去重、陈旧结果拒绝和教师复核保护；它不能评估真实手写识别准确率。认证、营队成员、题库和文件来源采用测试边界，数据库与阅卷持久化使用真实实现。

准备好隔离库并在插件目录安装开发依赖、构建后，在 `SpringBoot/CodeArena` 执行：

```sh
XSDTOP_GRADING_TEST_JDBC_URL='jdbc:mysql://127.0.0.1:13316/grading_test?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=UTC' \
  mvn -q -Dtest=CampExternalGradingMySqlTest -Dtest.excludedGroups= test
```

常规回归：后端 `mvn -q -Dtest.excludedGroups=db test`；前端 `npm run test:run`、`npm run type-check`、`npm run build`；插件源码 `npm run typecheck`、`npm test`。发行仓库另外运行 `npm test` 和 `npm pack --dry-run --json`，核对 Skill、工具、版本与安装包内容。
